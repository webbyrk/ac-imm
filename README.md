# Interactive Media Management – Algonquin College

A static website created for the Interactive Media Management program at Algonquin College. The site showcases program details and student projects with responsive design and interactive elements.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap 5
- Owl Carousel
- Google Fonts (Open Sans)
- Material Symbols (Google Icons)
